# Frontend

React application for submitting and managing tickets.

Stack: React, Tailwind CSS, Recharts, React Router and Axios.

Pages:

- Login and Register
- Dashboard with KPI cards and charts
- All Tickets with search, filters, pagination, date range and export
- Ticket Detail
- Submit Ticket
- User Management
- Profile

Setup:

1. Run `npm install`.
2. Run `npm start`. The app opens on port 3000.

The Submit Ticket form has no category dropdown. The AI service classifies each ticket after it is submitted.
